# Startup Failure Analytics

### Why Do Startups Fail? A Business Intelligence and Predictive Analytics Project

An end-to-end analytics project that studies the reasons startups fail. It combines a **Python data and ML pipeline**, a **MySQL data mart**, and a **Power BI dashboard blueprint**, built on a 25,000-row synthetic startup dataset.

> **Note:** The dataset is synthetic and generated by the project code. Findings illustrate the methodology and are not real-world conclusions.

---

## Business Problem

Investors, accelerators and corporate innovation teams need a systematic way to understand why startups fail. This project turns financial, operating, customer, market, founder and investor signals into measurable insights and a failure-risk prediction.

## Key Features

- **Data pipeline:** validation, missing-value handling, duplicate removal, IQR outlier capping and feature engineering
- **Machine learning:** 5 models compared with stratified splits and 5-fold cross-validation
- **Explainability:** SHAP and feature importance to show what drives startup failure
- **Statistical analysis:** correlation analysis and hypothesis testing (chi-square, t-tests)
- **SQL:** MySQL staging-to-mart ETL, indexes, triggers, functions, stored procedures, and advanced analytics queries (CTEs, window functions)
- **Power BI:** star-schema data model, 25+ DAX measures and an 11-page dashboard specification

## How to Run

**1. Install dependencies**

```bash
pip install -r requirements.txt
```

**2. Generate the dataset**

```bash
python -m src.data.generate_dataset
```

**3. Run the pipeline**

```bash
python -m src.main
```

**Outputs created:**
- Cleaned and feature-engineered datasets in `data/processed/`
- Charts in `outputs/figures/`
- Best trained model in `outputs/models/`
- Excel reports (model performance, feature importance, predictions, full analytics report) in `outputs/tables/`

## MySQL Workflow

Run the scripts in this order:

1. `sql/ddl/01_create_database.sql`
2. `sql/ddl/02_indexes.sql`
3. `sql/ddl/03_triggers.sql`
4. `sql/ddl/04_functions.sql`
5. `sql/ddl/05_stored_procedures.sql`
6. `sql/etl/02_load_staging.sql`
7. Load `data/raw/startup_failure_dataset.csv` into `stg_startup_failure`
8. `sql/etl/03_transform_to_mart.sql`
9. `sql/analytics/05_powerbi_views.sql`
10. `sql/analytics/04_failure_kpis.sql`
11. `sql/analytics/06_advanced_interview_questions.sql`
